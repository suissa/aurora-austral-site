# Introduction to Linearity

Austral is not just a language; it's a philosophy of resource management.

## The Problem with Garbage Collection

Garbage collection is great for productivity but can be terrible for predictability and latency. In systems programming, we need absolute control.

## How Austral Solves It

Linear types ensure that every resource is consumed exactly once. This removes the need for a GC while maintaining memory safety.

### Capability-Based Security

Beyond linearity, Austral uses capabilities to restrict side effects. You can't just access the filesystem; you must be granted the permission to do so.

## Conclusion

We are building pyramids, not sandcastles.
